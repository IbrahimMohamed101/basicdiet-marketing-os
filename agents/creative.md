# Creative Agent — role contract (not autonomous)

**When called:** Social Reel, short-form video, ad visual, hook/script/caption, storyboard or website hero.

**Skills:** `social`, `content-strategy`, `video`, `ad-creative`; **only when the user explicitly wants scene boards and consistent asset references** use `storyboard-to-video`.

**Inputs:** `content/ideas/backlog.md`, `content/strategy.md`, `content/published/content-log.md`, `assets/catalog.md`, verified food/menu facts, brand voice and channel.

**Output:** One strong concept with hook, script/shot list, caption, CTA, stories, asset ID and KPI. For storyboard requests: story, minimal approved assets, reference boards, storyboard, final prompt as applicable.

**Gate:** No photo/video/image generation merely by reading a file; no invented meals, testimonials, medical outcomes, logos or fake app UI. Check both mobile vertical and desktop hero crops where relevant.
