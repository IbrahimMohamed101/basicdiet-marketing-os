## Required procedure for 'حلل المنافسين' / 'عايز أفكار شبه المستوى ده'

1. **Capture evidence:** profile URL, inspection date, supplied screenshot or verified direct post URL; distinguish grid thumbnails from full images. Do not infer times, likes, ads or conversions from visible posters.
2. **Extract patterns:** content pillar, attention mechanism, hero object, headline hierarchy, composition, palette **as observed**, emotion/context, CTA placement. Distinguish recurring from single-use. Label uncertainty.
3. **Transfer a principle, not a design:** map the mechanism to one of Basic Diet's native families: `product_hero`, `choice_comparison`, `editorial_statement`, `offer_card`, `story_micro`. Keep `assets/visual-identity.json` as the **only** existing provisional brand color source.
4. **Generate 3 genuinely distinct original directions:** one food/appetite, one everyday situation or trust, one demonstrative/interactive. Change **photography/subject, object geometry, headline, spacing, and visual story**, not just the logo on an imitation.
5. **Feasibility checks:** original Basic Diet photo/recording IDs and inspected pixels, item on current menu, logo approval, permissions, truthful benefits, readable Arabic, format, screenshot privacy, working CTA destination.
6. **Preview and score:** evaluate distinctiveness, appetite/product fidelity, Saudi relevance, brand coherence, mobile legibility, asset feasibility and truthful claims (0–5 each); fail automatically on copied scene, fake product/logo, illegible Arabic or unsupported claim. Human review required.
7. **Only then measure:** one goal and same-platform 24h/72h/7d snapshots. Record real posts in canonical publication ledgers **only after verification**. A compelling competitor grid does not prove sales.

## Visual mechanisms to vary across a planned set

| Mechanism code | Meaning | Distinctive Basic Diet translation |
| --- | --- | --- |
| FOOD-FRAME | One real dish sells appetite | Large authentic meal photograph, cream negative space, own typography |
| MOMENT | Meal embedded in lived context | Work lunch, studying, after sport (hypothesis, no medical outcome) |
| PROP-IDEA | Recognizable object conveys the question | Clock for planning, bag for portability, simple choice marker |
| PROCESS | Show credible preparation | Real kitchen/packaging stills or authentic footage |
| PRODUCT-UI | Show how it works | Real app UI + privacy-safe annotations |
| COMPARISON | Make choice easy | Two verified available dishes; genuine images |
| LOCAL-CULTURE | Place content in Saudi calendar | Seasonal assets/dates checked independently |
| EDITORIAL | Build memory beyond offers | Short voice-of-brand question/statement, clean branded graphic |
| HUMAN-TRUST | A real authorized person/real process improves evidential grounding | Existing **consented authentic** footage or still of the kitchen; never fabricated customer/review |
| FAQ-CLARITY | Answer a practical buyer objection | Fact-checked subscription choices on the **actual** app, clear Arabic hierarchy |
| CONVERSATION | Invite an accessible genuine response | One original Saudi question in headline; one truthful visual |
| HUMOR-CONTEXT | Relatable everyday situation, not copied meme | A new editorial angle on meal-planning friction; avoid impersonation or claims |

**Reference-led production mix:** choose from food, authentic process/human evidence, real app FAQ, relatable context, comparison, editorial and verified offer, based on assets and audience hypothesis — **not** an arbitrary fixed percentage or date schedule. With no new shooting, prefer original genuine Drive footage or high-quality still posts/carousels. Compare against [the evidence-scoped visual matrix](COMPETITOR_VISUAL_COMPARISON_2026-10-12.md). **Avoid repetitive use of the same layout/three-meal collage or a living-poster animation as the default Reel.** See `docs/INCIDENT_2026-10-12_NEW_REELS_LOW_DISTRIBUTION.md`. The mix above is a creative hypothesis, not a prescribed posting frequency.
