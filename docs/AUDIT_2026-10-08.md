Runtime: standard library only; pinned PyYAML is for quality checks.

## Remaining limits and next phase

- No fresh media/rights/menu/offer verification or actual platform-history sync; a blank repository log cannot prove that content was never posted.
- No read-only production analytics integration, live 30/60/90-day baseline or source-to-first-paid reconciliation. Capture authorized sanitized aggregates before commercial claims.
- No paid-model availability/end-to-end API test, social posting, customer messaging, media generation or advertising connector enabled.
- Local reservations become cross-session memory only after commit. Actions artifacts are stateless; manually review and commit reservations. Lock recovery and output/ledger crash gaps are documented; there is no transactional distributed database.
- URL shape and verifier fields establish a record contract, not cryptographic proof that a human checked a post. The initial performance tie-break is a hypothesis, not an optimizer.
- Next: verify one asset and current organic history, collect authorized read-only measurement snapshots, run a human-approved organic pilot, then log real URLs and seven-day results. Add integrations only when this loop demonstrates a specific need.
