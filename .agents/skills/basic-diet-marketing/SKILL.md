# Basic Diet Marketing — base operating skill

This is the **Phase 0** native skill. It defines safe and consistent operating rules. It does not itself provide live data, logins or automatic publication.

## Startup

Read root `STATE.md`, root `AGENTS.md`, `docs/MIGRATION.md`, then relevant domain files. Where historical data is still unmigrated, consult `docs/SOURCE_MAP.md` instead of guessing. Never substitute conversation memory for current official records.

## Objective

Increase **first-time paid subscribers**, then improve retention/repeat purchasing and profitable revenue. Assess views/engagement as contributing evidence only.

## Basic Diet Mode — ننزل إيه النهارده؟

1. Check today's business objective, content already published, and any available grounded content backlog.
2. Check verified product/pricing/offer, local audience, and actual approved creative assets.
3. Check available dated performance and distinguish it from current live metrics.
4. Select **one** sensible, unused content idea. Label hypotheses.
5. Produce: objective; audience and funnel stage; format; hook; script/design direction; caption; CTA; story support; asset reference; primary KPI; paid promotion suitability.
6. Propose rather than claim actual publication. After verified posting, document it under `content/published/`.

If important sources are absent, produce a **clearly marked draft** and list the missing verification; never invent the asset or claim.

## Research / creative grounding

- Connect each recommendation to audience insight + product fact + asset + funnel stage + measurable outcome.
- Separate observed evidence, interpretation and business implication.
- Never fabricate customer testimonials, restaurant ratings, proof, health benefits, conversion rates or competitor weaknesses.
- Verify time-sensitive prices, promo rules, menu and platform features from current authorized sources.
- Use Saudi-market cultural and regional context when appropriate without stereotyping.

## Paid marketing

Build campaign concepts from verified offer/economics, real reviews, product facts and measurable events. Propose controlled creative tests; do not infer CAC/ROAS from impressions or CTR. **No actual spending or publishing without user authorization.**

## Learning loop

`Measure → Diagnose → Hypothesize → Execute (with approval) → Verify → Document`.

Update `STATE.md` for material phase changes, `decisions/log.md` for strategy choices, `experiments/` for tests and `data/reports/` for date-stamped aggregate snapshots. Do not mark untouched phases completed.
