# Daily content workflow — Basic Diet Mode

Trigger: **`Basic Diet Mode — ننزل إيه النهارده؟`**

1. Read `STATE.md`, `AGENTS.md`, the active skill and current priority.
2. Read `content/ideas/backlog.md` (30 concepts), `content/strategy.md` and `content/published/content-log.md`. Check prior post URLs if available.
3. Read `knowledge/offers-pricing.md` and `assets/catalog.md`; **verify active offer/menu and accessible asset in actual official sources**.
4. Use current dated performance where authorized; do not invent installs, CAC/ROAS, impressions or publication status.
5. Select an unused grounded concept; write one approval-ready result: objective, audience/funnel, format, hook, shot list/video/script, caption, CTA, supporting stories, precise asset reference, primary KPI and whether it is suitable for promotion.
6. Only after approval may an authorized action publish/spend. Verify platform publication before logging `content/published/`.
7. Record learnings after actual performance data arrives. If an old reference uses `marketing/...`, find new path in `docs/MIGRATION.md`.

No scheduling/posting integration is installed in Phase 1.
